# Информационная система учёта кадров организации

Веб-приложение для учёта сотрудников, ведения графика смен и расчёта заработной платы
с учётом совмещения должностей. Разработано в рамках выпускной квалификационной работы
(специальность 09.02.07 «Информационные системы и программирование»).

## Технологический стек

- **Backend:** PHP 8 (PDO)
- **База данных:** MySQL 8 / MariaDB
- **Frontend:** HTML, CSS, Bootstrap 5

## Возможности

- Справочник сотрудников: добавление, редактирование, поиск по фамилии, фильтр по подразделению
- Справочники подразделений и должностей (настраиваемые)
- График смен в виде помесячного табеля с назначением смен без перезагрузки страницы
- Автоматический расчёт заработной платы с коэффициентом совмещения
- Отчёты: по заработной плате, по загрузке подразделений, по совмещению должностей; выгрузка в CSV
- Аутентификация и разграничение прав по ролям (`admin`, `hr`)

## Структура проекта

```
includes/   — общие модули (подключение к БД, аутентификация, расчёт зарплаты, разметка)
pages/      — страницы интерфейса
api/        — обработчики запросов (AJAX, удаление, выгрузка CSV)
assets/css/ — стили
sql/        — скрипт создания и наполнения базы данных
```

## Установка

1. Скопировать файлы проекта в каталог веб-сервера (Apache/Nginx) с поддержкой PHP 8.
2. Создать базу данных и наполнить её, выполнив скрипт `sql/init.sql` в клиенте MySQL
   (например, в phpMyAdmin).
3. При необходимости указать реквизиты подключения к базе данных в `includes/config.php`.
4. Открыть приложение в браузере.

## Параметры расчёта заработной платы

Задаются в `includes/config.php`:

- `monthly_norm` — нормативное число смен в месяце (по умолчанию `22`);
- `combine_rate` — ставка надбавки за совмещение (по умолчанию `0.15`).

Итоговая сумма = базовая сумма × (1 + доля смен в чужих подразделениях × ставка совмещения).
